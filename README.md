# EquaTrack 💰

> A web-based personal finance management and PIN-authorized ledger sharing tool.

EquaTrack allows users to manage daily personal finances, track wallet balances, and manage shared group expenses effortlessly without requiring subscription fees or complex setups.

---

## ✨ Features

- **Split-Bill Calculator:** Simple splitting mechanism for group expenses and shared bills.
- **Ledger Security:** PIN-authorized ledger access and custom wallet IDs.
- **Zero-Cost Design:** Built for maximum usability on serverless architecture.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Storage/DB:** Local Storage & Firebase Integration
